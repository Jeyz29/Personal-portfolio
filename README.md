# Gustavo Berne — Engineering Portfolio (TypeScript + React 19 + Tailwind CSS v4)

Bilingual (`EN` / `ES`) software engineering portfolio showcasing production full-stack architectures, AI/LLM hubs, and multi-currency financial tools.

## Featured Engineering Case Studies (3)

1. **Multi-LLM Platform & AI Generation Hub — Kromaticos** (`Next.js`, `React`, `TypeScript`, `Tailwind CSS`, `Dynamic Context Memory`)
2. **Automated Course Registration & Payment SPA — UCV** (`Vanilla JS ES6+`, `Google Apps Script`, `Google Drive API`, `Serverless` — [Live in Production](https://extensionciencias.ucv.ve/cursos/))
3. **Multi-Currency Expense & Subscription Manager** (`React 19`, `TypeScript`, `Node.js`, `Express 5`, `SQLite`, `Recharts`, `Tailwind v4`)

## Local Development

```bash
npm install
npm run dev
```

## Production Build & Deployment (Vercel)

```bash
npm run build
```

Connect this repository to [Vercel](https://vercel.com) — Vite is automatically detected with zero configuration required.
